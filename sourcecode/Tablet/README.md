# I2C Monitor Tablet V22

PlatformIO firmware for the Guition JC3248W535C_I_Y ESP32-S3 tablet with a 320 x 480 LCD and capacitive touch. The tablet is the frontend: a separate RP2350 captures the DUT bus and performs requested active transactions. Use the companion RP2350 Sniffer V13 firmware for accelerated report and graph acquisition.

## Hardware And Wiring

Required hardware is the JC3248W535C_I_Y tablet, the companion WeAct RP2350B instrument, USB power/data cables, and three short UART wires. The display and touch connections are internal; no external display, SD card or Wi-Fi connection is required.

| From | To | Purpose |
| --- | --- | --- |
| RP2350 GP0 TX | Tablet GPIO17 RX | Transactions and diagnostics |
| RP2350 GP1 RX | Tablet GPIO18 TX | Commands |
| RP2350 GND | Tablet GND | UART reference |

Power the two boards through separate USB connections. Do not join their 5 V or 3.3 V rails. UART uses 3.3 V logic, not RS-232. Verify connector signals rather than relying on wire colors. Keep wires short for the negotiated 2 Mbaud link. UART starts at 115200 baud for rendezvous and supports monitored fallback.

Connect the DUT only to the RP2350 probes: GP30 SDA, GP31 SCL and signal GND. Do not connect the DUT to the tablet's internal touch I2C bus. Use 3.3 V DUT signals and retain existing bus pull-ups. Active operations reduce interference through idle admission and contention checks, but cannot guarantee exclusive access when another controller is present. Experimental writes and playback are unsuitable for safety-critical hardware.

## Build And Upload

Open this folder in VS Code with PlatformIO and select environment `tablet`, or run:

```powershell
pio run -e tablet
pio run -e tablet -t upload
```

Connect the tablet through a USB data cable. If multiple upload ports are present, specify the tablet port explicitly, for example `pio run -e tablet -t upload --upload-port COM18`. Do not select the RP2350 port.

PlatformIO installs the dependencies pinned in `platformio.ini`: Espressif32 6.12.0, Arduino GFX 1.5.9 and LVGL 9.2.2. The configuration enables the board's 16 MB flash, OPI PSRAM and native USB serial. Output is `.pio/build/tablet/firmware.bin`; use PlatformIO upload rather than copying this application binary to a bootloader drive. No compiled binaries or dependency caches are included in this source folder.

## Operation

Boot opens START, synchronizes the RP link and enables passive discovery. Confirmed I2C addresses unlock the tool screens. NEW SESSION clears observations while retaining settings and profile assignments; RESET CONFIGURATION also clears those settings and assignments, without removing installed profiles.

- **Monitor:** Sniff, Unique and Discover views, register filters, parsed values, and fading activity/change highlights.
- **Reports:** retained passive readings, property details, individual active reads, and accelerated Read Missing/Read All batches.
- **Graph:** predefined or manual property selection, START/STOP, history clear, and Passive, Passive/Active or Active acquisition. The 1-30 second interval is disabled in Passive mode. Passive/Active actively refreshes only properties without a recent successful passive observation; Active refreshes all selected properties.
- **Recorder:** filtered write recording, selected playback, timing and post-playback response inspection.
- **Read And Write:** manual register operations independent of profile definitions.
- **Diagnostics And Identification:** link/acquisition statistics, active address scans, and profile identification evidence.

IP2366, IP2368 and IP2369 fallback profiles are compiled into the supplied headers. Runtime profile loading and persistent address/profile assignments remain supported, but YAML sources and PC conversion/upload tools are intentionally excluded from this source-only package. Active reads, writes, scans and playback occur only through explicit requests; ordinary monitoring is passive.

## Project Layout

- `src/main.cpp`: application setup, hardware integration, UART handling and cooperative UI/job scheduling.
- `include`: UI modules, transport, acquisition models, runtime profile support, generated fallback definitions, fonts and LVGL configuration.
- `licenses`: included third-party license notice.
- `platformio.ini`: board settings, build flags and pinned dependencies.
- `.pio`: generated by PlatformIO when building; not distributed as source.

This is a clean copy of Tablet V22, including the correction that validates single-register batch replies against the requested register span rather than the unused companion-register field. Tests, screenshots, historical notes, RP firmware binaries and PowerShell tools remain in the full development project, not this folder.
